# P2PChain（骨架）

一个类似比特币的点对点挖矿区块链项目骨架，Go 语言实现，零外部依赖（当前阶段只用标准库），支持普通电脑 CPU 挖矿。

> ⚠️ 这是**学习/实验用骨架**，尚未做安全审计，不要用于任何真实资产场景。核心待办事项见 `docs/DEVELOPMENT_PROMPT.md`。

## 已实现的功能

- [x] 区块结构、区块头哈希、Merkle 根计算
- [x] UTXO 交易结构、Coinbase（出块奖励）交易
- [x] 工作量证明挖矿、难度调整算法
- [x] 内存版区块链（校验前置哈希 + PoW）
- [x] 密钥生成、地址（公钥哈希）、ECDSA 签名/验签
- [x] 基于 TCP 的 P2P 消息广播骨架
- [x] 内存版区块存储接口

## 快速开始

需要本地安装 Go 1.22+（当前沙箱环境未装 Go，代码已人工核对语法但未实际编译，首次运行请先 `go build ./...` 确认）。

```bash
# 启动第一个节点（矿工模式）
go run ./cmd/node --listen :6688

# 启动第二个节点并连接第一个节点
go run ./cmd/node --listen :6689 --seed 127.0.0.1:6688
```

启动后会看到类似日志：

```
[node] 矿工地址（公钥哈希）=3f2a...
[node] 创世区块哈希=00000...
[p2p] 节点已启动，监听地址 :6688
[miner] 开始挖矿，高度=1，难度位数=20
[miner] 挖到新区块！高度=1 哈希=00000... 尝试次数=182933
```

## 目录结构

```
p2pchain/
├── cmd/node/main.go         # 程序入口
├── internal/
│   ├── block/                # 区块 & Merkle树
│   ├── transaction/          # UTXO交易
│   ├── pow/                  # 工作量证明 & 难度调整
│   ├── blockchain/           # 链管理
│   ├── wallet/                # 密钥/地址/签名
│   ├── p2p/                   # 网络层
│   ├── storage/               # 持久化接口
│   └── config/                 # 配置
└── docs/
    └── DEVELOPMENT_PROMPT.md  # 专业开发提示词 / 模块任务卡片
```

## 调整挖矿难度（本地测试建议调小）

`internal/pow/pow.go` 中的 `MaxTargetBits` 决定初始难度，数值越大越难。本地单机用普通CPU测试建议先设置为 16~20，观察出块时间后再调整。
